What is not measured here

Tokens per task. Not recoverable retrospectively. Agent runs report their token use when they finish, but nothing writes it down, so there is no record to read. It becomes available once something appends to ops/caretaker/runs.jsonl — see ops/caretaker/run.mjs.

Actual effort. The board stamps a close date but no start, so elapsed below is calendar time from the first commit naming a task. A 2h task opened Monday and closed Friday reads as four days. That measures how long work SITS, which is what the ETA actually depends on, but it is not hours worked and must not be read as such.

Rework is measured now and is no longer on this list. Verdicts append, so the gate panel reports the real first-pass and rework rates rather than a snapshot of the latest verdict.

## Maintaining this

Generated from `the board named in ops/caretaker/config.json`. **Never edit the generated page.**

```
node ops/caretaker/board.mjs done T-012        mark complete, stamps today's date
node ops/caretaker/board.mjs start T-012       mark in progress
node ops/caretaker/board.mjs block T-012 "why" mark blocked with a reason
node ops/caretaker/board.mjs note T-012 "text" append a note
node ops/caretaker/board.mjs                   print the board to the terminal
```

Every mutating command rebuilds this page and the whole docs site, so it can never drift from the data.
